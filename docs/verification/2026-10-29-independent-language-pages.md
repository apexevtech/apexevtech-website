# 中英文独立网址与语言切换验收

日期：2026-10-29（Asia/Shanghai）。

## 当前状态

本记录是发布提交前的本地验收快照。英文入口为 `https://www.link-jl.com/`，新增中文入口为 `/zh`；实际发布状态以对应提交的 CI、部署状态和交付时的线上响应复核为准，本地验证本身不代表已上线。搜索引擎重新抓取需另行观察，不声称 Google 已收录、统计后台已收到事件，或曝光、排名、点击率已经提升。

## 实际修改

### 独立网址与服务端中文

- 保留原有英文页面 URL，不增加 `/en` 前缀，不把已有英文地址重定向到中文。
- 为 55 个批准的公开页面增加 `/zh` 对应页。中文 HTML 由服务端直接输出正文、导航和结构化数据，不再依赖加载后读取浏览器偏好并替换英文文字。
- 英文根布局输出 `lang="en"`，中文根布局输出 `lang="zh-CN"`；URL 的语言优先于历史 `localStorage` 值和浏览器语言。不增加按 IP 或浏览器语言强制跳转。
- 站内页面链接随当前语言转换；查询条件、分页、比较型号和锚点保留。外部网址、图片、下载、`/api/inquiries` 等不增加语言前缀。
- 中文 `/zh/resources`、`/zh/library`、`/zh/engineering-cases` 复用原入口的查询归一化逻辑，以 308 跳转到中文项目案例集合。`/zh/applications` 以 308 跳转到中文解决方案锚点；原有英文入口继续兼容。

### 搜索元数据

- 每个中英文页面使用本语言的 self canonical，并输出互相对应的绝对 `en`、`zh-Hans`、`x-default` alternate；`x-default` 指向原英文对应页。
- 中文标题、描述、Open Graph、Twitter 文案及适用的 JSON-LD 文字和页面链接同步中文。型号、单位、标准编号、图片地址、外部身份链接和组织身份引用保持不变。
- 集合页保留已有的有效分页 canonical 规则；过滤条件、跟踪参数和锚点不被扩展成新的索引页面。
- Sitemap 包含 55 对、共 110 个页面及相互对应的语言 alternate；不纳入旧入口、过滤 URL、API 或下载文件。原英文内容日期保留，中文翻译发布日期单独记录。

### 询盘与切换保护

- 切换语言会进行完整页面加载，不是自动保存或跨语言恢复草稿。仅自动预填不会被标记成用户已编辑；真实输入、主动清空和应用需求配置会标记草稿变更。
- 有未保存草稿时请求确认，取消后保留原页面和草稿；提交进行中阻止切换，提交结束后清除阻止提示。
- 请求结果不确定时，提示先核实投递结果再重发；确认离开会清除本页输入和提醒，不自动重复提交。
- 不将姓名、邮箱、询盘正文等草稿存入 URL、历史记录或新的浏览器存储。
- 询盘 API 路径与业务字段语义不变。中文 `sourcePage` 在原有允许范围校验前仅去除一个 `/zh` 前缀，保持后台使用的英文规范路径；不放宽重复前缀或非允许路径。
- 隐私政策链接在对应语言的新窗口打开，不覆盖原询盘页面；下载、邮件、电话和 WhatsApp 外部行为保持原边界。

### 多根布局的 404 修复

无 JavaScript 验收发现，多根布局下部分未知网址虽返回 404，初始文档却缺少可见错误正文。已增加完整的全局错误 HTML 文档、英文及中文说明、两个首页入口和明确的 `noindex`，用于没有匹配路由的地址，不以英文内容加 200 状态冒充中文兜底页。

进一步检查发现，当前 Next 动态 `notFound()` 的错误恢复仍可能仅内联 Flight、留下空白 HTML。仅增加全局错误页并不能解决未知详情地址。因此新增范围受限的 `proxy.ts`：仅对中英文公开页面命名空间中的未知 GET/HEAD 路径，按现有页面注册表提前返回完整双语 HTML、HTTP 404 和 `X-Robots-Tag: noindex, follow`。已知页面、四类旧入口、查询条件、写入请求、API、资源文件和下载均不被替换。未知 RSC 请求返回 HTML，允许客户端按文档响应回退，不返回伪造 Flight。

实现遵循当前项目安装的 Next 16.4.2 文档，使用 `experimental.globalNotFound: true`。该选项仍属实验功能，后续升级 Next 时应重新验证未知英文路径、中文路径及未知详情 slug 的状态、正文和 robots，而不能仅凭构建通过判断。
