# Legacy product document redirects — 2026-09-22

The 12 historical `/product-documents/*.docx` files were removed after their product pages moved to stable ASCII `/downloads/*-specifications.docx` URLs.

Each exact historical URL now returns a permanent redirect to the corresponding clean download. This preserves old bookmarks and Google crawl signals while eliminating duplicate binary files and punctuation-heavy paths. Clean downloads keep their attachment and `noindex, nosnippet` headers; technical specifications remain indexable in each HTML product page.
