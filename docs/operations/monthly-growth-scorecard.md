## Decision rules

- Wait at least 28 complete days after a material title or content change before judging the result, unless indexing or rendering is broken.
- Improve the existing landing page when the query intent already matches it. Create a new page only when the search intent and content scope are clearly distinct.
- Prioritize pages with impressions and positions 5–25 before pages with no demonstrated demand.
- Treat a lead as successful only when the inquiry API confirms delivery or a tracked WhatsApp, email or phone action occurs.
- Record deployment date and commit so changes can be tied to the next measurement period.

## Monthly procedure

1. Export Search Console page and query data for the latest and previous 28-day periods.
2. Record GA4 sessions, organic sessions, engagement, inquiry starts and generated leads.
3. Review Clarity recordings only for pages with drop-off, dead-click or form-friction signals.
4. Check Resend delivery, bounce and complaint status for website inquiries.
5. Select no more than three page-level changes for the next period.
6. Add the release commit and deployment date to the scorecard.
