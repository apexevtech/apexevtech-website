# Original technical evidence asset brief

Prepared: 2026-10-12

## Priority asset

Prepare one anonymized **EVSE end-of-line test record example** to support the highest-opportunity query cluster. The public version should demonstrate how a production test result is made reviewable without identifying a customer or claiming certification.

Preferred source material:

- one approved software screenshot showing test steps or result status;
- one anonymized result export or report page;
- model or product-family label that can be published;
- the test software version and report date, if approved;
- confirmation that customer names, serial numbers, IP addresses and confidential limits have been removed;
- written approval for public website use.

The finished website asset should explain:

1. how the charger variant selects the correct test program;
2. how the station records stimulus, measured value, limit and result;
3. how failed units retain the first result and repair or retest history;
4. how the record links to the unit without exposing confidential identifiers;
5. which parts are engineering evidence and which parts require separate conformity assessment.

## Second-priority asset

Prepare one anonymized **post-installation EVSE commissioning record** for the query `evse testing after commissioning`.

Preferred source material:

- charger identity and site-precondition checklist with sensitive fields removed;
- one normal charging-sequence screenshot or timeline;
- one measurement or protocol observation;
- the accepted handover or follow-up fields;
- written approval for public website use.

## Publication rules

- Do not invent measurements, customers, certifications or pass results.
- Do not publish personal contact details, serial numbers, private site information, IP addresses or access credentials.
- Label templates and reference workflows clearly when they are not records from a completed customer project.
- Retain the approved source and publication permission internally.
- Use descriptive image filenames and provide an explanatory caption and alternative text.
